# Code of Conduct

## Our Pledge

We are committed to creating a welcoming and respectful community for everyone.

## Expected Behavior

- Be respectful.
- Be professional.
- Help others learn.
- Accept constructive feedback.
- Communicate politely.

## Unacceptable Behavior

- Harassment
- Hate speech
- Personal attacks
- Discrimination
- Sharing private information without permission
- Spam or malicious activity

## Enforcement

Project maintainers may remove comments, issues, or contributions that violate this Code of Conduct.

## Contact

For questions, please contact the project maintainer through GitHub Issues.
